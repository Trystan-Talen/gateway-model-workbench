# 模型指纹：使用与方法

## 入口与流程

左侧“模型指纹”与网关压测、路由对照、质量评测同级。

1. **通道自检**：填写接口地址及本次密钥，点击模型下拉框右侧的“获取模型”，再选择一个模型（接口不支持列表时，点击下方“无法获取列表？手动指定模型”），选择采集范围，确认请求数量后开始。没有参考也能运行。停止会取消在途请求，保留已结算证据。
2. **采集参考指纹**：直接从“参考库”页面点击“采集参考指纹”。填写可信资源的接口地址和密钥，获取并选择一个模型，额外填写可追溯的来源说明并声明来源可信。完整采集后自动进入参考库。可信是使用者的声明，系统不能验证提供方身份。
3. **对照已有参考**：选择当前可用参考，采样范围、每格次数、并发、RPM（每分钟请求数）、超时、接口适配自动沿用。只向待测通道发请求；参考数据在本地复用。旧参考未限制速率时保持原协议，不套用新建默认值。
4. **离线对照**：已结算记录可重新选择参考；不发模型请求、不产生上游费用。不兼容的参考仅显示探索性距离。

模型列表仅在点击按钮后读取一次，不会开始指纹采集，也不读写其他模块保存的密钥。修改地址或密钥后，旧列表和选择会清空；无法获取列表时可手动填写服务商支持的准确模型名称。列表里可见并不保证该模型支持固定采样参数。

结果页包含总览、回答分布、通道诊断、协议与来源、原始样本。原始样本每页 50 条，可下载全部样本；“导出指纹”保存协议与分布摘要，供参考库重新导入。

## 默认思考模型怎样测试

原有直接回答协议的单次输出上限为 16 词元。部分模型先生成推理，推理也占用输出预算，因此可能出现请求成功但正文为空、结束原因为长度上限；另一些模型不支持关闭思考，或拒绝温度、核采样参数。这是请求协议不兼容，不能据此判定模型不可用。

在新建页的“回答协议与接口适配”中明确选择：

| 选择 | 发送参数 | 用途 |
|---|---|---|
| 直接回答／关闭思考 | 原有 16 词元上限，保留既有固定采样参数 | 接口支持关闭思考时，继续使用原方法 |
| OpenAI（开放人工智能）兼容接口：保留思考 | `max_completion_tokens`（推理与正文合计上限）＝4096；`reasoning_effort`（推理强度）＝`low`（低）；不传温度和核采样参数 | 支持这组参数的聊天补全接口，含无法关闭思考的模型 |
| DeepSeek（深度求索）：保留思考 | `max_tokens`（输出合计上限）＝4096；`thinking.type`（思考模式）＝`enabled`（启用）；`reasoning_effort`（推理强度）＝`low`（低）；不传温度和核采样参数 | 深度求索及明确兼容其参数的接口 |
| 智谱 GLM（通用语言模型）：保留思考 | `max_tokens`（输出合计上限）＝4096；`thinking.type`（思考模式）＝`enabled`（启用）；`reasoning_effort`（推理强度）＝`low`（低）；不传温度和核采样参数 | 智谱 GLM-5.3／5.3-Flash／5.3-FlashX 及明确兼容这些参数的接口 |

**GLM-5.3-Flash（智谱闪速模型）的处理**：其官方接口不能关闭思考。标准协议的 16 词元可能在推理阶段用尽，产生状态码 200、正文为空、长度截断；旧“智谱：关闭思考”适配又会发送不受支持的禁用参数。应新建采集，手动选择“智谱：保留思考”，确认较高输出上限后开始。温度和核采样是智谱支持的参数；本协议选择不发送它们、沿用接口默认值，并非宣称智谱不支持采样。

对已知官方域名 `api.z.ai`（智谱国际接口）、`open.bigmodel.cn`（智谱国内接口）及上述三个精确模型名称，新建和复测预检会拦截不兼容的旧适配，不访问上游。旧记录与参考仍可查看、导出；需要重新采集思考协议参考，不能直接改旧参数。中转地址只给兼容提示，不根据模型名认定上游协议；需确认中转支持智谱参数和输出限制。

保留思考是独立的 `workbench-reasoning-one-word/1`（思考后单词回答协议第一版）。只将最终正文纳入回答分布，推理内容和推理内容块不能充当答案；只保存观测标记及上游回传的推理用量，不保存独立推理字段或推理内容块的全文。即使参考采用同一思考协议，当前也只展示探索性距离，不直接套用原方法的 0.25／0.35 一致性阈值。旧直接回答协议、已有记录与参考摘要不变，不能与新协议混比。

选择后先核对单次和全计划上限，再勾选费用确认。标准 200 次计划的推理与正文合计上限为 819,200 词元，输入另计；这不是预计消费或商家账单。4096 是本工作台的有限采集预算，不保证所有模型都能在此预算内回答。不会自动切换到这个更高预算、取消硬上限或收费重试。连续 3 次正文为空且在推理阶段截断会停止后续请求，保留用量和诊断；接口拒绝参数也立即停止。复测和参考对照沿用冻结参数，重新展示费用风险。

本次只实现上述明确的参数协议，不按模型名字猜测供应商，也不把某种“关闭思考”参数发送给所有中转。仅支持流式或其他专用协议的模型、忽略硬上限的代理仍需单独适配。开发验证全部使用本地传输替身，未调用付费上游。

协议依据核对于 2026-10-16（新加坡时间）：[OpenAI（开放人工智能）聊天补全参数](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)定义推理和可见输出的合计上限；[模型参数兼容说明](https://developers.openai.com/api/docs/guides/latest-model)说明部分推理模型不支持关闭思考或采样参数；[DeepSeek（深度求索）聊天补全文档](https://api-docs.deepseek.com/api/create-chat-completion/)定义思考模式、低强度设置和输出上限。[智谱闪速模型说明](https://docs.z.ai/guides/vlm/glm-5.3-flash)与[深度思考参数](https://docs.z.ai/guides/capabilities/thinking)明确强制思考与低强度支持；[核心参数](https://docs.z.ai/guides/overview/concept-param)定义单次生成上限。[国内官方端点说明](https://docs.bigmodel.cn/cn/api/introduction)用于精确域名识别。供应商参数可能变化，拒绝时应核对其当前文档后新建合适的冻结协议。

## 冻结协议

| 项目 | 实现 |
|---|---|
| 范围 | 8 类问题，中英各一格，共 16 格；每格 3–4 种改写 |
| 默认方案 | 快速 4×15＝60 次；标准 8×25＝200 次；扩展 16×25＝400 次 |
| 可调整范围 | 每格 10–100 次；并发 1–20（默认 20）；RPM（每分钟请求数）为 1–600000 的整数（默认 100）；单次总超时 5–120 秒 |
| 固定采样 | 直接回答：温度 1、累计概率上限 1、输出预算 16；保留思考：不传这两个采样参数、推理与正文合计预算 4096、低强度思考。均不流式、不重试 |
| 消息 | 每次仅一条固定系统提示和一条问题；不带历史、工具或记忆 |
| 隐式状态 | 不继承供应商的会话标记，不使用环境代理，不跟随重定向 |
| 随机排程 | 种子落盘；先分配每格重复编号与改写，再打乱全队列 |
| 发送节奏 | 新协议按速率间隔开始请求，并发仅限制在途上限；等待与并发不足不会积累突发额度，停止后不再发送待发样本 |
| 协议摘要 | 包含题库摘要、归一化版本、参数、适配器与系统提示；数字规范化后计算，浏览器文件往返不会改变摘要 |

接口支持标准聊天兼容协议、显式关闭思考适配，以及上述三种保留思考适配。选择不同适配方式即形成不同协议。服务器拒绝参数时会停止，不会悄悄增大输出预算、探测其他接口或自动改用其他推理设置。

默认速率为每分钟 100 请求，标准方案 200 次请求约需 120 秒发完，计划请求数不随并发增大；实际耗时还取决于单次响应和并发上限。速率、并发与其他采样参数一起冻结；已有不含速率字段的协议仍可导入、对照和复测，摘要保持原值。

每次响应记录发送编号、格子与改写编号、时间、延迟、状态码、回答原文、归一化结果、结束原因、回显模型、响应标识和用量。原文最多 4096 字符，网络响应最多 1 兆字节。缺失用量与费用保留未知；部分回传的合计明确标注覆盖次数。

## 判读规则

采用 JSD（詹森–香农散度），范围 0–1；越小表示两次观测分布越接近，不是模型身份置信度。

- 双方每格至少 10 个有效答案；至少 4 格且覆盖计划格数的 80%。
- 协议完全一致、来源已声明可信、采集完整，才能进入行为一致性判读。
- 参考与待测采集日期不得明显超前；任一超过 30 天会阻止直接判读。**30 天是本地工程策略，非论文结论。**
- 有效率低于 80%、错误率超过 10%、截断超过 5%、解释性额外文本超过 20%、观测到推理、输出预算回报超限、重复响应标识或分半异常，均使结论降级。
- 两种分半分别按每格重复编号交替拆分、实际发送时间前后拆分；每半至少 5 个有效样本。自检差异超过 0.25 仅提示复测。
- 条件满足后，距离不高于 0.25 提示“行为分布相近”；高于 0.35 提示“行为差异明显”；中间为证据不明确。

阈值借鉴上游工程实现，未经当前供应商校准。高分半距离可能来自小样本噪声、改写分配或通道变化；低分半距离不能排除稳定比例的混合后端。不能据此认定供应商造假或证明底层模型身份。

数字、字母、硬币答案进行确定性规范化；拒答、空答、截断和明确解释分别保留分类。不会把多词回答的第一个词直接当有效样本。中文开放词域使用确定性形式规则，不能保证每个短字符串语义上确为动物或城市；没有引入另一个模型评分，以免增加不可控协议。

## 缓存与方法边界

前缀计算缓存和完整响应重放是两回事。前缀复用通常是计算优化；实际部署仍可能受数值精度、批处理和非确定性实现影响，不宜承诺所有服务端都逐位等价。完整响应重放可能影响分布，需另行排查。

本模块按供应商回报的缓存词元分组显示延迟；缺失字段不会被当成“未命中”。重复答案不能证明缓存，改写池也不能保证避开缓存。回显模型名称可以提示别名或路由差异，但不证明实际模型身份。

用户提供的“系统提示变动产生约 0.44–0.46 散度”在上游说明中有相应陈述；本次未在论文正文定位到可独立核实的同数值结果，因此实现不把它当成通用阈值或统计保证。

## 文件、恢复与导入

数据独立保存在项目的 fingerprint_data（指纹数据目录）内，运行记录和参考分开管理，已加入版本控制忽略规则。目录权限为 700，文件为 600。每条样本落盘，摘要原子替换；新进程恢复运行中的任务为“进程中断”，不会续发请求。损坏记录隔离并显示恢复提示。

密钥仅在执行内存中使用；任务结束后清空，接口响应和文件不保存密钥。前端关闭抽屉、退出登录或失去会话时清空密钥。重新采集需要重新输入。

参考导入支持本工作台摘要和上游单份指纹对象，最大 2 兆字节。会校验计数、日期、诊断结构与协议，重算能从计数推导的指标；未知额外字段丢弃。文件没有数字签名，导入者仍需核实来源。

上游历史参考与本工作台协议不同，保留原日期和外部协议标记，不能冒充兼容参考；本模块不内置、改写或伪造历史基线。删除运行记录不会级联删除已独立建立的参考。
