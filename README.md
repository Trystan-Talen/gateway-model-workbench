# 网关压测工作台

用于对 OpenAI 兼容网关做黑盒压测，只展示客户端能够客观观测的请求状态、成功率、TTFT（首字耗时）、总耗时、实际吞吐与调度积压。

## 启动

```bash
python3 -m pip install -r requirements.txt
python3 route_test_ui.py
```

打开 `http://127.0.0.1:8666`。

当前开发验证端口也可使用 `ROUTE_TEST_PORT=18666 python3 -u route_test_ui.py`，访问 `http://127.0.0.1:18666/`。

## 安全

API Key（应用程序编程接口密钥）不会写入 `tasks.json` 或浏览器本地存储。历史配置只保存非敏感字段。

## 质量评测

默认120题、12个维度；单资源做能力诊断，双资源做同题配对、退化分析与选型复核。查看《质量评测方法.md》了解评分、题集建设、内部阈值与结论边界。

- 创建前可审阅全部题目、答案与规则；单资源120次、双资源240次请求，会产生实际资源费用。
- 当前题集／方法版本3：10道指令题采用逐条约束判分，双资源逐题交替先后顺序；主质量分与约束辅助诊断分开。
- 创建摘要、题集与报告提供“评测方法与官方参考”入口，列明7个公开框架的借鉴部分和未覆盖能力；不冒充官方基准成绩。
- 新任务冻结方法来源与执行协议，旧任务不补造历史方法。
- 报告可导出为可阅读的结论与机器可读证据；未开启原始记录时不补造完整输出。
- 原5题历史只保留为冒烟观测，不提升为120题结论。

本地单元回归：

```bash
python3 -m unittest discover -s tests -v
```

浏览器回归位于 `tests/browser/workflow.cjs`、`tests/browser/quality_v2.cjs` 、`tests/browser/auth_focus.cjs` 与 `tests/browser/modal_layout.cjs`，需要本机浏览器和 Playwright（浏览器自动化库）。只对临时目录和本地模拟上游发请求，不调用用户真实资源。

登录焦点回归覆盖会话失效、慢速输入密码、键盘切换、密码显隐、重新登录及过期请求回调；避免后台轮询反复抢走输入焦点。

详情弹窗统一为外壳裁切、固定标题、正文内部滚动；桌面与小屏均保留底部圆角，嵌套弹窗只关闭顶层。弹窗打开时会话失效，先释放旧弹窗焦点约束，再进入登录，避免抢走密码输入焦点。
